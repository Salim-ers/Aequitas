# Documentation Aequitas

- `product/` — périmètre fonctionnel, feuille de route
- `architecture/` — décisions techniques structurantes
- `security/` — mesures en place et à venir
- `regulatory/` — trajectoire réglementaire, ports et adaptateurs
- `billing/` — offres, quotas, cycle Stripe

Chaque document décrit ce qui **est**, et signale explicitement ce qui ne l'est pas
encore. Aucune section ne doit décrire une fonctionnalité comme livrée avant qu'elle
le soit.
